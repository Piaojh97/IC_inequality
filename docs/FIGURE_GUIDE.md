## Main figures

Numerical panels are generated by `code/reproduce.py --main N`. The original assembled layouts remain in `reference/figures/Figure_N.pdf`.

| Figure/panels | Data | Code and output |
|---|---|---|
| **1a:** minimum relative entropy | `data/empirical/min_entropy_histogram.csv` | `main_1()`; redraw the 100-bin distribution |
| **1b:** severity criteria and follow-up diversity | `data/empirical/threshold_depth.csv` | `main_1()`; the blue curve is the entropy criterion used by the original plotting code; the orange curve is mean follow-up entropy among classified users |
| **1c:** persistence | `data/empirical/persistence_by_status.csv` | `main_1()`; group means and intervals; summary statistics also recover the reported two-sided t test |
| **1d–g:** age risks and disparity across thresholds | `data/empirical/age_risks.csv`, `data/empirical/thresholds.csv` | `main_1()`; age-group risks and normalized age gaps; the risk-ratio values are also available in the threshold table |
| **1h–i:** adjusted curves | `data/statistical_results/regression_curves.csv` | `main_1()`; draw the saved regression curves |
| **1j:** age coefficients | `data/statistical_results/regression_all_specifications.csv` | `main_1()`; display the five saved specifications; logistic age coefficients are exponentiated |
| **2a–d:** exploration and exploitation | `data/empirical/behaviour_by_age_status.csv` | `main_2()`; age-by-status group means |
| **2e:** age-group behavioural distributions | `data/model/inputs/age_behaviour_distribution.csv` | `main_2()`; redraw the six constituent distributions; the assembled author layout is retained separately |
| **2f–g:** behavioural schematics | `reference/artwork/Figure2.ai`, `reference/figures/Figure_2.pdf` | Editable schematic illustrations |
| **3a–c:** empirical/model risk landscape and agreement | `data/statistical_results/calibration_cell_support.csv` | `main_3()`; redraw both grids and calculate R² directly from the 100 public cell pairs |
| **3d–e:** simulated persistence and depth | `data/model/outputs/population_status.csv` | `main_3()`; group summaries of the saved simulated population |
| **3f:** simulated age gradient | `data/model/outputs/population_risks.csv` | `main_3()`; age-group risks and normal binomial intervals |
| **4a–c:** intervention risk landscapes | `data/model/outputs/phase_grid.csv` | `main_4()`; the original beta=6, exploitation-score=9 and exploration-score=3 slices |
| **4d–f:** oldest-group intervention responses | `data/model/outputs/intervention_curves.csv`, `data/model/outputs/population_risks.csv` | `main_4()`; three dose-response curves and the youngest-group reference |

The original empirical preparation and plotting logic is retained in `reference/analysis/`: `data_cleaned.ipynb`, `figure1&SI.ipynb`, `figure2.ipynb`, `figure3.ipynb`, `figure4.ipynb` and `empirical_vs_theory.ipynb`.
